# Benny the Bunny and the Magical Rainbow Apples

## Scene 1 — A Woodland Adventure (00:00–00:40)

A self-contained, browser-playable animated storybook scene introducing Benny, Lulu and Teddy in a sunny forest. It includes animated character movement, woodland scenery, timed dialogue and narration, and a magical rainbow reveal.

### Play the scene
Open **[scene-1/index.html](scene-1/index.html)** in a modern web browser. No build tools, server, or external libraries are required. Press **Play scene** to start the 40-second sequence, **Pause** to pause, and **Restart** to begin again.

### Character designs
- **Benny:** small white bunny, pink inner ears, blue waistcoat, expressive eyes.
- **Lulu:** orange fox, cream muzzle, purple dress.
- **Teddy:** cuddly brown bear, green scarf.

### Scene beats
- 00:00 — Sunny forest establishing view and narrator introduction.
- 00:07 — Benny invites his friends to explore.
- 00:13 — Lulu responds enthusiastically.
- 00:18 — Teddy wonders what they will find.
- 00:25 — The friends laugh and follow the woodland path.
- 00:31 — A magical rainbow glow appears between the trees.
- 00:37 — The narrator invites the audience to follow the sparkle.

### Technical notes
This is a lightweight 2D SVG/CSS/JavaScript animation prototype, not a rendered MP4 or a 3D animation. Edit the inline SVG artwork, CSS keyframes, and dialogue cue list in `scene-1/index.html` to customise it. The page respects the browser's reduced-motion preference.
